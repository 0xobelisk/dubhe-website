# Historical Labs translations

These JSON files preserve the original `labs.labsList.bridge` and
`labs.labsList.network` objects from the matching
`apps/web/messages/<locale>.json` at commit
`0f6de93523f403334da514fb8d9534acdc2c785d`.

The active English schema does not contain these two groups. A source search
confirmed that the Labs page selects only `dubheos`, `obelisk`, `cyferio`, and
`numeron`; no application code references the archived groups. The unused
groups were moved here to restore identical translation structure across
locales while preserving their original string and array values.

This directory is a historical source archive, outside the active message
catalog. Its contents are not verified current product, team-size, or staffing
claims and must not be republished as such without review. Public infrastructure
pages and links are unaffected.
